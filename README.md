# Collage Maker — downloads

Grid, shape and photomosaic collages. Everything runs on your device.

**Get the latest:** [Releases →](https://github.com/eldad3D/collage-maker-releases/releases/latest)

- **Windows:** `CollageMaker_x.y.z_x64-setup.exe` — installs per user, updates itself.
- **Android:** `CollageMaker_x.y.z.apk` — allow "Install unknown apps" once; the app tells you when a new APK is out.

Source code is private. This repo only hosts builds.
